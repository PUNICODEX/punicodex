The Authentic Name

Unicode restoration and ASCII comparison

Scholarly Transliteration

Taaroa

The name survives in scholarly transliteration. Taaroa is the standard Polynesian romanisation, documented in academic sources — “The distant one”. Because the spelling uses only Latin letters, the form is the same in both ASCII and Unicode.

No indigenous writing system is securely attested for individual polynesian names. The form shown is a modern scholarly transliteration.

ASCII Constraint

taaroa

The plain taaroa form is identical to the Unicode restoration. Because this name is already written in Latin letters, no diacritics, stress, or script information were lost — only capitalization differs.

Unicode Restoration

Taaroa

The Unicode restoration does not need to recover lost marks for Taaroa. Its value is canonical spelling and consistent cataloguing, not the reconstruction of erased orthography. The domain is readable as-is to both DNS and humanity.

Punycode Encoding
Taaroa.com → taaroa.com

The non-ASCII characters in Taaroa are encoded while the ASCII remains visible. To the DNS, it is Punycode. To humanity, it is Taaroa.
