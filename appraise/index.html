Unicode Domain Appraiser

The first valuation model built for Unicode / IDN domain names. It anchors every name to its ASCII control value, then values the Unicode form at 10% of that anchor and applies transparent percentage boosts for canonical form, tier, scholarly sources, brand scarcity, safety, and TLD reality. The Unicode domain itself is never valued above its ASCII root; tenant revenue is reported separately.
