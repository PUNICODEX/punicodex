VERCEL DEPLOYMENT
-----------------
For each domain above, add a Domain in Vercel:
  1. Go to Project Settings → Domains
  2. Add the Punycode domain (e.g., xn--seln-dvab.com)
  3. Vercel will provide DNS records to add at your registrar
  4. Repeat for each domainAlt

NOTE: Register all domains at your preferred registrar using
      the Punycode form. The browser will display Unicode automatically.
