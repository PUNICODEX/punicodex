# PuniCodex Authenticity — Wearables

Lightweight classifier samples for wearable notifications.

- `apple-watch/PunicodexWatchClassifier.swift` — watchOS 8+ notification filter.
- `wear-os/AuthenticityWatchService.kt` — Wear OS notification filter.

Both reuse the offline model from the iOS/Android SDKs while keeping binary
size minimal.
