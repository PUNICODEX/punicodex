PUNICODEX — 3D VISUAL SYSTEM · PLACEMENT GUIDE
Version 3.0 · 2026 · prepared after a full re-review of every page of punicodex.com
================================================================================

This guide tells you (and Kimi Code CLI) EXACTLY where every asset in
13-page-visuals/ belongs, why it belongs there, and how to wire it in.
Every PNG is transparent, rendered at 1100–1600px, and pre-lit for the
obsidian (#0A0A0C) page background — no further color work needed.

HOW TO READ THIS DOCUMENT
-------------------------
Each page gets: the concept, the files, the precise DOM location, sizing,
alt text, and a copy-paste CSS/HTML fragment. Serve the kit from
/assets/brand/ so paths below resolve, e.g.:

  /assets/brand/13-page-visuals/tiers/triad-ziggurat.png

UNIVERSAL WIRING (put these helpers in your global CSS once)
------------------------------------------------------------
/* place any of these renders floating over obsidian with a warm floor glow */
.pc-art {
  position: relative;
  filter: drop-shadow(0 30px 60px rgba(0,0,0,.65))
          drop-shadow(0 0 42px rgba(212,175,55,.14));
}
/* slow museum float — pairs with punicodex-motion.css */
@keyframes pc-float {
  0%,100% { transform: translateY(0); }
  50%     { transform: translateY(-14px); }
}
.pc-art--float { animation: pc-float 7s ease-in-out infinite; }
@media (prefers-reduced-motion: reduce) { .pc-art--float { animation: none; } }

================================================================================
SECTION C — GLOBAL FINISHING NOTES
================================================================================
C1. Layering: all renders are transparent with baked contact shadows; over
    #0A0A0C they need no blend modes. Over imagery, add the obsidian glow
    (03-ornaments/punicodex-glow-gold-radial.png) beneath at 60%.
C2. Performance: every <img> above includes width/height — keep them (CLS).
    Add loading="lazy" to everything below the fold; fetchpriority="high"
    only for each page's hero art.
C3. Motion: hero art takes .pc-art--float; everything else stays still.
    One moving object per viewport is the house rule.
C4. Consistency: all 20+ renders share one light rig (warm key upper-left,
    cool fill, gold rim, horizon-band env) — they will read as one family
    next to the v1/v2 gold work. Do not re-color; if you need variants,
    the full render pipeline is in /mnt/agents/work/punicodex-brand-gen/
    (render3d.py, scenes3d.py) — every scene is parametric.
C5. Accessibility: alt texts are supplied per placement. The art is
    decorative-supportive, never the sole carrier of meaning.
