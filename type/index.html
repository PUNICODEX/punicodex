The Engine

TYPE

A predictive typing system for scholarly transliteration. Type a name. The system constrains you to valid Unicode paths only. Invalid keystrokes are rejected. Valid ones restore the gods.

01

Constraint, Not Conversion

Most tools convert after you type. PuniCodex Type blocks invalid paths in real time. If no attested name begins with your keystrokes, the input is rejected. You cannot type garbage.

02

Scholarly Trie

Every entry in the lexicon is sourced from accredited transliteration systems: Greek with pitch accent and vowel length, Norse with eth and thorn, Egyptian with alef and ayin. No invented spellings.

03

Teach By Restriction

When you complete a valid name, the system shows exactly which characters changed and why. Stress. Length. Special characters. Each transformation is annotated with its philological basis.
