# ICANN SSAC Consultation Response

**Date:** 2026-06-22
**Status:** Submitted
**Audience:** ICANN Security and Stability Advisory Committee (SSAC)

## Summary

PUNYCODEX responds to ICANN SSAC consultations on IDN security, emphasizing registrar-level confusable alerts, rapid revocation, and machine-readable transparency reports.

## Key Points

1. Registry-level script restrictions are necessary but not sufficient.
2. Registrars should receive confusable alerts at registration time.
3. STIX/TAXII should be adopted for sharing high-confidence IDN indicators.
4. Quarterly transparency data should be machine-readable.
