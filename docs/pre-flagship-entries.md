# PuniCodex — Plain-ASCII Pre-Flagship Entries (the promotion queue)

Generated from the canonical lexicon (type/js/lexicon.js) against the flagship archetype list
(js/archetypes-v2.js). These 50 entries are the non-flagship names whose lexicon
restoration is PURE ASCII — a plain transliteration with no preserved diacritics, marks, or
original script. Every other non-flagship entry in the lexicon already preserves at least one
distinctive feature (accent, macron, diacritic, or original-script character), so this list is
exactly the set that needs new restoration materials before promotion.

They are the promotion queue: each one you prepare materials for can become a flagship via
`node scripts/promote-to-flagship.js <id> [--domain <domain>]`.

Sorted by pantheon (largest queue first), entries alphabetical within each tradition.
