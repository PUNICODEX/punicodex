# Fine-Tuning a PuniCodex Model on Nemotron — Guide & Recipe

**Goal:** an owned "PuniCodex AI" trained on the canonical corpus
(`data/corpus/*.jsonl`) without buying hardware. The answer is a **LoRA
fine-tune of a small open-weight model on a rented GPU** — tens of dollars,
not thousands. Full pretraining is neither affordable nor useful at this
corpus scale; fine-tuning is the correct tool.

## Why Nemotron, and which size

NVIDIA's Nemotron 3 family (2026) is open-weight under the permissive
[OpenMDW-1.1 license](https://tech-insider.org/nvidia-nemotron-3-ultra-open-weight-2026/),
which explicitly covers derivative fine-tunes — and NVIDIA ships the
training recipes. Variants:

| Variant | Params (total/active) | Fits our job? | Hardware for LoRA |
|---------|----------------------|---------------|-------------------|
| Nemotron 3 Nano | ~8–14B | **Best first target** — cheap, fast iteration | RTX 4090-class rental (~24GB) with QLoRA |
| [Nemotron 3 Super](https://stackbuiltai.com/nemotron-3-super-review-2026/) | 120B / 12B active | The quality sweet spot once Nano proves the loop | 1× A100 80GB |
| Nemotron 3 Ultra | 550B / 55B active | Overkill; revisit when traffic justifies it | multi-GPU — skip for now |

Alternatives worth knowing (same recipe applies): Llama 3.1 8B, Qwen 3 8B,
Mistral Nemo. If Nemotron's hybrid Mamba layers fight the tooling, Qwen 3 8B
is the most documented LoRA target in Axolotl today.

## What the corpus already gives you

Everything is Alpaca/chat JSONL, generated by `npm run generate`:

- `instructions-train.jsonl` (26 MB) — instruction/input/output, the core SFT set
- `chat-train.jsonl` (83 MB) — multi-turn dialogues
- `reasoning-examples.jsonl`, `oracle-examples.jsonl`, `mythology-synthesis.jsonl`,
  `symbolic-correspondences.jsonl`, `scientific-analogies.jsonl` — capability flavors
- `safety-examples.jsonl` (28 MB) — refusal/safety behavior
- `preference-examples.jsonl` — chosen/rejected pairs for an optional DPO pass
- `pronunciation.jsonl` — IPA/respelling/SSML per entry (voice-facing skills)
- `eval.jsonl` + `chat-eval.jsonl` — **held-out evaluation splits; never train on them**
- `benchmark.jsonl` — the capability probe for before/after comparison

Mix for v1: instructions-train + reasoning + oracle + a 10–20% slice of
safety-examples. Chat-train in v2 once single-turn behavior is solid.

## The $ path (no 5090 needed)

| Route | Cost for v1 | Effort |
|-------|-------------|--------|
| **Rented GPU, self-run** (vast.ai / RunPod: RTX 4090 ~$0.4–0.7/hr; A100 80GB ~$1.5–2.5/hr) | **~$2–5** (Nano, 2–4h) · ~$15–30 (Super, 6–12h) | Axolotl config below; one command |
| **Serverless fine-tuning** (Together, Fireworks, OpenPipe, HF Jobs) | ~$10–50 per run | upload JSONL, click train |
| Buy a 5090 desktop | $3,000+ | only when training weekly |

NVIDIA also runs a [free NIM prototyping tier on DGX
Cloud](https://nevercodealone.de/de/vibe-coding/vibe-coding-modelle/nvidia-nemotron-foundation-modelle-agentische-ki-2026)
— useful for smoke-testing the base model before spending anything.

## Recipe (Axolotl, Nemotron Nano, rented 4090)

```bash
pip install axolotl
# fetch the corpus files listed above into ./data/
axolotl train docs/fine-tuning/axolotl-nemotron-nano.yaml
axolotl inference docs/fine-tuning/axolotl-nemotron-nano.yaml --lora-model-dir ./out
```

The committed config (`docs/fine-tuning/axolotl-nemotron-nano.yaml`) is
tuned for the corpus: QLoRA 4-bit load, r=32, 2 epochs, packed 4096-token
sequences. On a 4090 expect ~2–4 hours.

## Evaluate honestly

1. Hold out `eval.jsonl` — run base vs fine-tuned on it; expect large gains
   on lexicon recall (punycode, IPA, breakdowns, sources).
2. `benchmark.jsonl` is the capability probe; compare before/after.
3. Spot-check the failure mode that matters: the model must **cite and
   refuse** per the safety corpus, not hallucinate etymologies.

## Straight talk

- A fine-tuned 8B will learn the lexicon's facts, formats, and voice. It
  will not be frontier-smart — for open-ended reasoning a hosted frontier
  model with RAG over `/api/v1/names/*` still wins. The fine-tune's value is
  ownership: an offline, brandable, zero-marginal-cost PuniCodex model.
- Data moat > model moat: the corpus is the asset; the recipe above is
  re-runnable as open models improve. Re-train quarterly for ~$5.
- Do not train on `eval.jsonl` / `chat-eval.jsonl` / `benchmark.jsonl` —
  contaminated evals lie.
