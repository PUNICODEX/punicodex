## Authentication

The Scholarly Edition uses password-based authentication.

1. Users sign in at `/scholars/login/index.html` with email and password.
2. Sessions last 7 days and are stored in `scholars_sessions`.
3. Account lockout occurs after 5 failed attempts for 15 minutes.
4. Users change their own password via `/api/v1/scholars/auth/password`.
5. Institution admins can reset passwords for users in their institution.
6. Curators can disable or re-enable any account.

Password requirements:

- Minimum 8 characters.
- Stored as bcrypt hashes (12 rounds).
- Temporary passwords may be generated by institution admins; users should change them on first sign-in.

## Curator Setup

Create the first curator locally or in production:

```bash
node scripts/create-scholar-curator.js curator@university.edu "secure-password"
```

Then the curator creates institutions and institution admins through the curator admin dashboard or the API:

```bash
POST /api/v1/scholars/institutions
{
  "name": "Example University",
  "slug": "example-university",
  "domain": "example.edu",
  "accreditation": "Regional",
  "adminEmail": "admin@example.edu",
  "adminPassword": "temporary-password",
  "adminDisplayName": "Dr. Admin",
  "adminDepartment": "Classics",
  "sponsorshipStatus": "active",
  "departmentAllowlist": ["Classics", "History", "Religious Studies"]
}
```

If `adminPassword` is omitted, a 20-character temporary password is returned.

## Institution Admin Onboarding

1. Sign in at `/scholars/login/index.html`.
2. Change the temporary password on first login.
3. Go to `/scholars/institution/index.html`.
4. Add students and promote reviewers:
   - `POST /api/v1/scholars/institution/students`
   - `POST /api/v1/scholars/institution/reviewers`
5. Manage the department allowlist through the curator if needed.

## Revocation

- Institution admins can disable students and reviewers in their institution (`DELETE /api/v1/scholars/institution/students/:id`).
- Curators can disable any account (`PATCH /api/v1/scholars/users/:id/status`).
- Disabled accounts cannot sign in or submit edits.
