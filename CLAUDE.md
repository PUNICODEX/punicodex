## What this is

PuniCodex is a multi-platform product around Unicode (IDN) domain names: an 895-entry scholarly lexicon across 22 pantheons, 895 static "temple" pages under `sites/{id}/` (196 hand-crafted flagships), a crawler/search engine for `xn--` domains, a domain-leasing platform, a homograph/brand-protection subsystem, a Scholarly Edition, a TCG (`/cards/`, `/game/`), a print-on-demand store (`/store/`), AI training-corpus exports, and many clients (extensions, PWA, Android, Electron, SDKs).

Plain Node.js ≥ 20, CommonJS, no TypeScript, no frontend framework — static HTML/CSS/vanilla JS. Hosted on Vercel (static + serverless `api/` + edge `middleware.js`). Express dev server in `platform/`. SQLite via `better-sqlite3` (ephemeral `/tmp` on Vercel — handlers re-migrate/re-seed on cold start).

## Commands

```bash
npm test                    # master runner: node test/run-all.js (136 suites, sequential)
npm run generate            # regenerate ALL derived artifacts (46 scripts, dependency order)
npm run generate:check      # divergence gate: verify generated files match canonical sources
npm run prepush             # npm test && npm run generate:check
npm run validate            # lexicon validator + accuracy validator + engine tests
npm run lint / lint:fix     # Biome
npm run format / format:check
npm run db-init             # build SQLite DB + all migrations (platform/db/)
npm run platform            # Express server on http://localhost:3456
```

**Run a single test suite** by invoking the file directly — suites are plain Node scripts or `node --test` files (see the `SUITES` array in `test/run-all.js` for the exact command per suite):

```bash
node test/store-orders.test.js
node --test test/cards.test.js
node platform/scholars/auth.test.js
```

## The one rule that governs everything: the generation flywheel

Canonical hand-edited sources → `npm run generate` → many generated consumers. **Never edit generated outputs by hand.** CI fails if generated files diverge from canonical sources (it reruns `npm run generate` and diffs).

Key canonical sources (edit these):
- `type/js/lexicon.js` — the 895-entry lexicon, single source of truth
- `type/js/original-scripts.js`, `source-catalog.js`, `pronunciation-atlas.js`, `glyph-atlas.js`
- `js/archetypes-v2.js` — the 196 flagship archetypes (domains, canvas)
- `platform/db/owned-domains.json`, `scripts/lore-catalog.json`
- `platform/public/scholars/` and `platform/public/admin-portal/` (root `scholars/` and `admin-portal/` are generated copies)
- `platform/blog/content/{id}.json`, `platform/scholars/content/{id}.json`

Key generated outputs (never hand-edit): `sites/{id}/` temples, `middleware.js` `DOMAIN_MAP` block, `extension/shared/` + `mobile/shared/` lexicon copies, `store/products.json` + all `store/` pages, `game/cards.json`, `blog/index.html`, `texts/`, `data/corpus/*`, `data-version.json`, root `scholars/` and `admin-portal/`.

**Workflow for any canonical-source change:** edit source → `npm run generate` → `npm test` → commit both the source and regenerated files.

Prefer the safe-edit scripts over hand-editing multiple canonical files: `node scripts/add-owned-domain.js <id> <domain>`, `node scripts/promote-to-flagship.js <id> [--domain <d>]`.

## Critical guardrails (hard-won; see AGENTS.md for full detail)

- **`vercel.json`**: must keep exactly one instance of each top-level key — a past script appended a duplicate `redirects` array and broke routing. Overwrite whole-file, never append. Domain routing does NOT belong here — it lives in `middleware.js`.
- **`middleware.js`**: all domain redirects/rewrites (Unicode/punycode deity domains → `/sites/{id}`). Its `DOMAIN_MAP` is generated by `scripts/sync-middleware-domains.js` — don't hand-edit inside the markers.
- **`ACCURACY.md`**: authoritative standard for any lexicon/original-script/temple content change. Consult before editing entries.
- **CSS/JS edits must ship with a `?v=` version bump** — `/css`, `/js`, `/assets` are immutable-cached for a year on Vercel.
- **Vercel catch-all functions** need explicit `vercel.json` rewrites with `:slug*` capture; the routers in `api/*/[[...slug]].js` read `req.query.slug` as one slash-joined string. Guarded by `test/vercel-config.test.js`.
- **Webfonts are self-hosted** (`/assets/fonts/`) — never re-add `fonts.googleapis.com` links (CSP drops them; `test/fonts-selfhosted.test.js`).
- Root `sw.js` must never intercept `/api/` or `/admin-portal/`; bump its cache revision on any change (`test/service-worker.test.js`).
- **Tier system is mechanical, not editorial** (see AGENTS.md "The Definitive Tier System"): exactly 3 dual-tier names (Apollo, Hekate, Nike); Tier-1 vs Tier-2 is computed from stress/length/diacritic features. Ownership and prominence are display facts, never tier criteria.
- **Deploys**: master pushes deploy automatically via CI once the full battery passes (`deploy-prebuilt.yml`). Never run a `vercel deploy --prebuilt` from Windows (win32 native binaries kill the Lambdas); local fallback is `vercel deploy --prod --yes --archive=tgz`.

## Code style

Biome 2.5 (`biome.json`): 2-space indent, LF, width 100, single quotes, semicolons, ES5 trailing commas, `require('node:fs')` protocol enforced. CommonJS throughout. Generated `sites/`, `extension/` (v1), most of `mobile/`, and `middleware.js` are excluded from formatting.

## Working in this tree (practical notes)

- The tree is huge (node_modules, 895 `sites/` dirs, gitignored `.masters/` media). **Repo-root Glob/Grep can time out — always scope searches to a specific directory** (`type/js/`, `platform/`, `api/`, `scripts/`, `test/`).
- Windows host, but npm scripts with `NODE_ENV=...` prefixes and `./gradlew` are POSIX — use the Bash tool for those.
- `npm test` runs 136 suites sequentially and is slow; while iterating, run the specific suite(s) touched, then the full battery before finishing.
